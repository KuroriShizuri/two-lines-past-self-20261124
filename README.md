Two lines, 265 characters: a warning to my past self not to spend sixteenth-birthday money on a limited-edition game skin — the game shuts down within a year — and why losing it changed how I pay for things.

> Do not spend your sixteenth-birthday money on that limited-edition game skin — the game shuts down within a year, and the skin goes with it.
>
> Losing it taught me to pay only for things that outlive the platform, since anything the servers hold was never really mine.

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the gate (1–280 characters, exactly 2 lines, exactly 1 sentence per line, not only white space), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.
